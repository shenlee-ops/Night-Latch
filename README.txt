NIGHTLATCH v1.9 — FINAL PORTABLE RELEASE
Windows 10/11 (x64)

This package contains the same NightLatch v1.9 executable that was reported
working by the user. No code changes have been made for this final package.

INSTALL / UPGRADE
1. Exit older NightLatch from its system tray icon (right-click > Exit).
2. Extract the entire ZIP into a permanent folder, such as:
   C:\Users\<you>\Apps\NightLatch\
3. Open NightLatch_v1.9.exe.
4. Set or verify the screensaver and Windows lock shortcuts.
5. Enable Start with Windows from the app if you want it at sign-in.
   If startup was already enabled with a different .exe location, switch it
   off and back on to update the startup path.

DEFAULT SHORTCUTS
 Ctrl + Alt + S   Start selected Windows screensaver
 Ctrl + Alt + L   Lock Windows

OTHER CONTROLS
 Closing the window hides it to the system tray.
 Right-click the tray icon and select Exit to quit fully.
 The icon is embedded in the .exe; NightLatch.ico is included only
 as an optional asset.

SECURITY AND COMPATIBILITY
 The app is unsigned. Smart App Control may restrict execution.
 Do not disable Windows security protections just to run it.
 Normal operation does not need administrator rights or a background service.

VERIFICATION
 SHA256SUMS.txt identifies the exact executable inside this package.
 Source and build instructions are available in the separate source ZIP.
